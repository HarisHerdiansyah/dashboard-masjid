### How to Setup?
1) Make sure you already installed Node.js v22+ or LTS version.
2) Install `pnpm` as package manager. See the [documentation](https://pnpm.io/installation).
3) Clone this repository.
4) Install package using command `pnpm install`.
5) Run the application using command `pnpm run dev`.
6) Open `http://localhost:3000` in your browser.
